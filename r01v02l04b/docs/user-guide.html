Getting Started

Karaoke Night is a personal song finder — open it by tapping Let's Sing! on the landing page. Your first step is to have a session: your singers, categories, and songs.

Create or load a session

Session → NewBuild a session from scratch using the inline entry panel.
Session → OpenLoad your saved session file(s).
Session → Open SampleLoad the built-in example to try out the app — easy to edit.
Session → DownloadGet a Sample or Blank Session to build and maintain in a spreadsheet or text editor. See Session Files for the format.
Session Menu

The Session menu controls loading and managing your session. Some items are disabled until a session is loaded.

Session

OpenLoad one or more saved session files. Warns if a session is already loaded.
NewBuild a session from scratch using the inline entry panel. Disabled once a session is loaded — use Add to append singers.
AddLoad one or more additional session files and append their singers to the current session.
ReopenOptionally drop singers, then opens the Add file picker. Useful mid-party.
Save As...Saves the current session as a file — includes all edits, excludes dropped/deleted items.
CloseClears the session and returns to the welcome screen.
Open SampleLoads the built-in sample session.
Download →Download Sample Session or Blank Session template to your device.
ExitReturns to the landing page.

Singer

Drop Singer(s)Removes selected singers from the session. Saved for Undrop.
Undrop Singer(s)Restores dropped singers. Disabled when nothing has been dropped.

💡 Mid-party tip: Use Add to load a new singer without disturbing the current session. Use Drop Singer(s) to remove singers who have left.
View Menu

The View menu controls how singers and categories are displayed. Items are disabled when there is nothing to act on or when an edit is in progress.

View

Singers ›Expand All or Collapse All singer panels.
Categories ›Expand All or Collapse All category panels within expanded singers.
All ›Expand or Collapse all singers and categories at once. Active only when there is something to expand or collapse.
Editing Your Session

Every singer header, category header, and song card shows a small ✏️ pencil icon. Tap it to open the edit menu for that item.

✏️ Edit Menu

RenameOpens an inline text field. Enter commits, Escape cancels.
DeleteRemoves the singer, category, or song from the session immediately.
Add Above / BelowSingers and categories — inserts a new item above or below. Type a name and press Enter to add it; a blank entry finishes.
Add Before / AfterSongs — inserts a new song before or after in the card grid. Same Enter flow.
Artist & URLOptional fields. After entering a song, you can add the artist name (🎼) and/or a direct URL link (🌐). Press Enter to confirm each field or Escape to skip. You can enter one, both, or neither — all combinations are valid.
💡 Tip: Use Save As... after editing to save your updated session.
Browsing Songs

Songs are organized in a Singer → Category → Song hierarchy. Tap any header to expand or collapse it.

1
Tap a Singer header to expand
Shows all categories for that singer. Tap again to collapse.
2
Tap a Category header to expand
Shows the song cards in that category.
3
Tap a song card
Opens a search for that song in the current search mode. If the song has artist or URL data, icons appear on the card — 🎼 shows the artist name (tap to search song + artist), 🌐 navigates directly to a preset URL.
4
Tap Back to return
Your scroll position, open sections, and search state are all restored automatically.
Searching

Two search tools are available in the top controls bar.

🔍
Filter
Searches your loaded session. Narrows singers and categories to matching songs only. Tap ✕ to clear and restore full view. Tap ▼ to pick from your recent filters. Disabled until a session is loaded.
▶
Find on YouTube
Search YouTube directly for any song — no session needed. Type a song name and press Enter. Tap ✕ to clear, or ▼ to pick from your recent searches.
💡 Tip: Use Filter to quickly find a song in your session list. Use Find on YouTube for ad hoc searches for songs not in your session.
Search Modes

The four mode buttons next to the Find box control how songs are searched. The active button appears pressed/darker.

🎤
Karaoke Mode (default)
Searches YouTube for karaoke [song title] — finds backing tracks with lyrics.
🎵
Music Video Mode
Searches YouTube for [song title] music video.
▶
YouTube Mode
Raw YouTube search — no prefix or suffix added. Good for finding specific versions.
G
Google Search
Opens a Google web search in a new tab. Useful for finding lyrics or song info.
💡 Tip: Your selected mode is remembered if you navigate back from a search. Web mode opens in a new tab so the app stays open.
Troubleshooting
ProblemFix
Session won't loadMake sure you're opening a session you saved or downloaded from this app. Try Session → Open Sample to confirm the app is working.
No singers showingThe session may have no entries. Open Session → Open Sample to verify the app is working, then check your file.
⚠️ icon in the headerSome rows in your session couldn't be read. Tap the ⚠️ to see which rows had problems, fix them, and reload.
Filter not workingA session must be loaded first — the Filter is disabled until a session is open.
Scroll position lostMake sure you tap Back — don't close the YouTube tab. The app restores scroll position on Back navigation.
YouTube opens wrong searchCheck which mode is active — 🎤 Karaoke, 🎵 Music Video, ▶ YouTube (raw), or G Google. The lit button is the active one.
Open Sample failsThis feature requires an internet connection — it fetches the sample file from the app server.
App looks wrong after updateHard refresh the page: Ctrl+Shift+R on desktop, or clear browser cache on mobile.
Session Files For experienced users

Most people never need this — just use Session → New or Open Sample. This section is for users who'd rather build and maintain a session in a spreadsheet or text editor.

A session file is a .csv file that defines your singers, categories, and songs. It can be created and edited in any spreadsheet app (Google Sheets, Excel, LibreOffice Calc) or a plain text editor. Use Session → Download to start from a Sample or Blank session.

File Format

Column 1# marks a comment row — entire row is ignored by the app
Column 2Singer name
Column 3Category name
Column 4Song title
Column 5Artist — optional, enter inline or in the file
Column 6Full URL — optional, enter inline or in the file
💡 One row can do multiple things: A single row can define a Singer, Category, and first Song all at once — just fill in columns 2, 3, and 4 together.
⚠️ Rows that don't fit the format: If a file has rows the app can't read, the session still loads and a ⚠️ warning icon appears in the header. Tap it to see exactly which rows had problems, then fix them in your spreadsheet and reload.
